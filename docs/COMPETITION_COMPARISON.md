> ⚠️ **结论口径**：本节所有比较都是**探索性、双侧、未做多重性校正**的，各组在长度、组成与抽样框上均不相同，

## 0. 方法说明

对竞赛 Top10 执行与本 pipeline 相同的流程：

1. **靶内对接**：RAPiDock vs NK2R（10 构象，取保留的最低 REF15 total model score）
2. **结构近邻对接**：对同一套 27 条 NK2R structural neighbours（与研究候选共用）
3. **逐近邻配对比较**：`delta = candidate − receptor-matched control`（对照 `HKTDSFVGLM`）；
   **fraction with a higher structural-neighbour score** = `delta > 0` 的比例（源字段 `frac_safer`）

### 长度校正

竞赛肽为 6/9/15 残基，研究候选为 10 残基。REF15 是**全原子能量和**，肽越长原子越多、分数越高，
跨长度直接比较无效。

**长度对照**：对每种长度生成 5 条**组成匹配的随机对照肽**（氨基酸组成取自对应长度的竞赛肽），
用同一流程对接 NK2R：

| 肽长 | 随机对照均值 ± SD | n |
|------|------------------|---|
| 6-mer | 625.7 ± 14.4 | 5 |
| 9-mer | 780.0 ± 105.9 | 5 |
| 10-mer | 687.4 ± 52.0 | 5 |
| 15-mer | 1502.0 ± 547.8 | 5 |

线性拟合：`pos = −107.7 + 100.6 × 长度`（R² = 0.568，P = 0.0001）——长度偏差约 **100 分/残基**。
**该拟合不隔离纯粹的"长度效应"**，因为各长度的对照组成不同。

**长度校正 z 值** =（候选分数 − 同长对照均值）/ 同长对照样本 SD。

> 使用局限：每长度仅 5 条对照，15-mer 组 SD 极大（547.8）使 z 被压缩，10-mer 组 SD 小（52.0）使 z 更严格；
> 跨长度组比较 z 需谨慎，优先在同一长度组内比较。NK2R-02（11 残基）无对应基线，从 z 分析中剔除
> （仍保留在原始分与 fraction 比较中）。

**计数摘要**

* 长度校正 z < 0：**9/10**
* Delta-on < 0：**5/10**
* fraction > 0.50：**8/10**
* 联合规则（Delta-on < 0 且 fraction > 0.50）：**3/10**，其中 9-mer 为 **3/5**

**观察**

1. 竞赛前 10 有 9/10 低于同长随机对照均值，但**这并不证明它们优于随机肽**——对照组成与长度池不同，
   且比较未校正。
2. 冠军 Y0002（EC50 = 2.07 nM）长度校正后 z = −1.23；顺序上与效价方向一致，但见 §3。
3. **COMP-03（CFYFLM，6-mer）是"单一分数会误判"的示例**：原始分数全场最低（608.69，Delta-on = −162.4，
   靶内判据通过），但其 fraction 仅 **0.19**——在多数结构近邻上比对照打分更高，因此不满足联合规则。
   这说明**单看原始对接分数不足以排序候选**，也说明结构近邻比较与靶内打分承载不同信息。
4. 15-mer Y 系列 fraction 较高（0.78–0.89），但因长度付出了约 500 分的原始分数代价，Delta-on 全为正。

## 2. 与研究候选的并置（descriptive，不作性能主张）

| 指标 | 竞赛 Top10 | 研究 NK2R 候选 |
|------|-----------|--------------|
| Delta-on < 0 | 5/10 | **23/32** |
| 长度校正 z < 0 | 9/10 | 11/31（10-mer） |
| fraction > 0.50 | 8/10 | 14/18 可评估 |
| 联合规则 | 3/10 | 10/18 可评估 |

分母不同（10 vs 32/31/18），分组不可交换；此处只做**描述性并置**。
稿件正是以此说明：这些**计算指标**与实验终点、筛选规模不可放在同一性能轴上比较。

## 3. 对接打分的预测力

对 10 条有实测 EC50 的竞赛肽：

| 比较 | Spearman ρ | P 值 |
|------|-----------|------|
| EC50 vs 原始分数 | +0.30 | 0.405 |
| EC50 vs 长度校正 z 值 | **+0.42** | **0.229** |

* 方向一致（分数越高 = 结合越弱 = EC50 越大），但 n = 10，**均无统计显著性，且未校正**。
* EC50 前 3：COMP-01、COMP-02、COMP-03；z 前 3：COMP-06、COMP-01、COMP-03 → 重合 2/3。
* **含义**：REF15 模型打分对实验效价只有不确定的弱预测力，不能作为 potency 的定量替代。
  有利的相对分数可支持计算排序，但其与效价的标定需要独立记录的实验测定。

### 探索性 Mann-Whitney 比较（双侧、未校正）

| 比较 | P 值 |
|------|------|
| 原始分数（10 vs 32 条研究候选） | 0.2204 |
| fraction（10 vs 18 条可评估） | 0.1699 |
| 长度校正 z（10 vs 31 条 10-mer） | 5.09 × 10⁻⁴ |

## 4. 复现

```bash
# 1. 从 Excel 提取 Top10 并生成对接输入
python scripts/make_comp_top10_inputs.py

# 2. 在 GPU 节点运行对接（正向 10 批 + 负向 11 批）
#    见 scripts/comp_top10_worker.sh 与 scripts/run_comp_top10_gpu.sh

# 3. 长度对照实验（20 条组成匹配随机肽）
python scripts/make_length_control.py

# 4. 汇总与作图
python scripts/summarize_comp_top10.py
python scripts/make_comp_table.py
python scripts/make_fig5_comparison.py   # -> Fig. S6
python scripts/make_fig6_headtohead.py   # -> Fig. S7
```

计算量：正向 10 复合物 + 负向 297 复合物 + 长度对照 20 复合物。

> **输入文件陷阱**：`COMP_TOP10_negative_docking_input.STALE-offby-one.csv` 的标签整体错位一格，
> 按复合物名查序列会取到相邻多肽；以 `comp_top10_neg_inputs/` 下的逐批次文件为准，并按**序列**合并。
