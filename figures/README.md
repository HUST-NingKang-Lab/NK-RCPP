## Regenerating

```bash
python scripts/make_ms_fig2.py && python scripts/make_ms_fig3.py && python scripts/make_ms_fig4.py
python scripts/make_fig8.py
python scripts/make_fig2.py && python scripts/make_fig3.py && python scripts/make_fig4.py
python scripts/make_supp_figs.py && python scripts/make_binding_modes.py
python scripts/make_fig5_comparison.py && python scripts/make_fig6_headtohead.py
```

Each script writes SVG + PDF + 600-dpi TIFF through `scripts/fig_style.py`; the TIFF is the large one and is
safe to delete. Scripts that still carry their original descriptive filenames are listed in the tables above —
they are the manuscript's figure sources, not duplicates.
